## Описание

Кольчуга Мёбиуса — это гибкая топологическая структура, состоящая из связанных колец Мёбиуса (торов со скруткой 180°). Каждое звено является самостоятельным резонатором, а вся цепь образует единую подвижную магнитную систему.

Это **первый гибкий топологический материал**, который может менять форму, сохраняя свои магнитные и резонансные свойства.

---

## Принцип работы

1. Каждое звено — кольцо Мёбиуса (скрученный тор).
2. Звенья соединены в подвижную цепь (кольчугу).
3. Вся структура может складываться, растягиваться, менять форму.
4. Магнитное поле течёт по цепи, как по волноводу, усиливаясь и модулируясь в каждом звене.

---

## Уникальные свойства

- **Гибкость** — меняет форму без потери свойств.
- **Самоорганизация** — выстраивается в определённые конфигурации под действием поля.
- **Переносимость поля** — поле течёт по цепи, как по живому кабелю.
- **Самовосстановление** — повреждённое звено можно заменить.
